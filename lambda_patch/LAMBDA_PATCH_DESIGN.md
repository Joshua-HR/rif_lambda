## 1. 목적

MD 방식은 SemiSyncOnlyMode에서 RIF 프래그먼트별 CIR만으로 "맞는 키의 STS가 들어왔는가"를 판정합니다. 분석 결과, 판정 통계량 Z의 H0 분포가 조건(신호 세기, 채널, 잔여 CFO × 길이)에 따라 바뀌어, 몬테카를로로 맞춘 두 단계 문턱이 측정한 두 끝점(−120 dBm, −40 dBm) 밖에서 깨집니다.

이 패치는 다음 두 가지를 합니다.

1. **판정 통계량 교체:** H0 분포가 어떤 조건에서도 같은 통계량 **Λ**를 도입합니다. 문턱은 몬테카를로가 아니라 공식으로 정합니다.
2. **분석 도구 확장:** 시뮬레이터 덤프에서 MD 방식과 Λ를 나란히 계산하고, H0 오검출률과 H1 감도를 비교하는 MATLAB 도구를 제공합니다. 기존 스크립트를 덮어쓰지 않고 `lambda_patch/`에 별도로 둡니다.

## 3. 알고리즘

### 3.1 핵심 관찰

상관기 출력은 `C[k] = Σ_n b_n · z_n[k]`입니다. b_n은 수신기 자기 키로 만든 ±1, z_n[k]는 lag k의 상관에서 b_n과 곱해지는 샘플입니다. H0(신호 없음, 틀린 키, 다른 세션, 키를 모르는 공격자)에서는 수신 신호가 b와 독립이므로, 수신 샘플을 고정하면 C[k]는 랜덤 부호 합이고 다음이 **정확히** 성립합니다.

```
E |C[k]|²  =  Σ_n |z_n[k]|²   ≡ Q[k]      (분산)
E  C[k]²   =  Σ_n  z_n[k]²    ≡ Π[k]      (의사분산: 비원형의 방향과 정도)
```

채널, CFO, 세기, 간섭의 종류와 무관합니다. MD 방식이 잡음 창 10개 탭으로 추정하던 바닥을 원시 샘플 M = (N−1)·128개로 계산합니다. M ≥ 3,968이라 C[k]는 가우시안에 가깝고, 랜덤 부호 합은 sub-Gaussian이라 꼬리가 가우시안보다 무겁지 않습니다.

### 3.2 판정 통계량 Λ

비원형 가우시안을 백색화한 2차형식입니다.

```
Λ[k] = 2 · ( Q·|C|² − Re(Π*·C²) ) / ( Q² − |Π|² )
     = 2 · ( |C|² − Re(π*·C²) ) / ( Q·(1 − |π|²) ),   π = Π/Q

H0:  P(Λ[k] ≥ t) = e^(−t/2)        (자유도 2인 카이제곱)
Π = 0 (원형 잡음)이면  Λ = 2|C|²/Q (MD의 Z와 같은 꼴)
```

- **클램프:** |π| = |Π|/Q는 0.98로 제한합니다(`RhoMax`). Q² − |Π|²가 0에 가까워지는 것을 막고, 강한 틀린 키에서는 판정이 보수적인 쪽으로 됩니다.
- **판정:** `valid = max_{k∈W_s} Λ[k] ≥ T`
- **위치 출력:** 정규화 전 |C|²의 argmax를 씁니다. Λ는 고SNR에서 여러 탭이 포화합니다.

### 3.3 문턱

```
T = 2·ln(|W_s| / Pfa) + 2·ln(Margin)        기본 |W_s| = 57, Pfa = 1e-3, Margin = 1.5  →  T = 22.71
```

탭 하나가 넘을 확률이 e^(−T/2)이고, 합집합 한계로 |W_s|배를 넘지 않습니다. Margin 1.5는 Q·Π를 유한 표본으로 계산하는 오차를 덮습니다. 길이, PRF, 세기, 채널, CFO와 무관합니다.

| \|W_s\| | Pfa 1e-3 | Pfa 1e-4 | Pfa 1e-6 |
|---|---|---|---|
| 57 | 22.71 (\|C\|²/Q 등가 10.55 dB) | 27.32 (11.35 dB) | 36.53 (12.62 dB) |
| 128 | 24.33 (10.85 dB) | 28.94 (11.60 dB) | 38.15 (12.80 dB) |
| 256 | 25.72 (11.09 dB) | 30.32 (11.81 dB) | 39.53 (12.96 dB) |

### 3.4 진단 지표

| 지표 | 정의 | 용도 |
|---|---|---|
| κ (`kappa`) | 바닥이 가장 높은 위상의 잡음 창 탭에서 \|Σ C²\| / Σ \|C\|² | 비원형 정도. 2열 덤프로도 계산. 열잡음 약 0.38, 강한 틀린 키(32심볼) 약 0.98 |
| ρ (`rhoPk`) | 피크 탭의 \|Π\|/Q | 자기잡음 지수. 열잡음에서는 0.1 이하 |
| `qRatio` | 잡음 창에서 mean(\|C\|²/Q) | 스케일 검사. 어떤 데이터든 약 1이어야 함 |

### 3.5 MMS 패킷 단위 소프트 결합 (선택)

프래그먼트마다 STS가 다르므로 H0에서 같은 탭의 Λ를 K개 더한 값은 자유도 2K인 카이제곱입니다. 문턱도 공식으로 정해집니다(K=4, |W_s|=57, Pfa 1e-3/1.5 → 36.96). 모델에서 4개 결합 시 L90이 −111.9 → −116.8 dBm(+4.9 dB)입니다. 프래그먼트 간 탭 정렬이 전제입니다. 이번 패치에는 포함하지 않았습니다.

## 4. 덤프 형식과 C++ 계약

### 4.1 형식

- 파일 이름: 기존과 같습니다. `<SignalPower>_RifCir_AccNum_<AccLen>_Frame<frame>_Samp<sample>.txt`
- 내용: 256줄(탭 0..255, 기준 안테나), 줄마다
  - 기존 2열: `re im`
  - 신규 5열: `re im Q PiRe PiIm`
- 한 폴더 안에서 2열과 5열을 섞지 않습니다(분석 도구가 오류로 막습니다).
- 출력 정밀도: 유효숫자 7자리 이상(`%.7g` 이상)을 권장합니다.

### 4.2 C++ 계약 (`RxSemiSync.cpp`, `semisync_only()`)

```cpp
// correlationAccBuf_Only 누적과 같은 루프, 같은 z
// z = STS 칩 b_n과 곱해지는 바로 그 값 (리샘플링/필터/위상 보정 이후)
corr[k]  += b_n * z;
momQ[k]  += std::norm(z);    // |z|^2
momPi[k] += z * z;           // z^2 (복소)
// 프래그먼트 시작 시 0으로 초기화, AccLen-1 구간도 corr와 동일
```

| 항목 | 요구 |
|---|---|
| 같은 샘플 | 상관기가 b_n과 곱하는 값 그대로(심볼별 가중치나 위상 보정이 있으면 그것까지 포함) |
| 같은 구간 | AccLen−1 심볼, 같은 시작·끝 |
| 같은 스케일 | CIR을 `>>3` 라운딩 후 값으로 덤프하면 Q·Π는 2⁻⁶배. LLS에서는 라운딩 전 부동소수점 값을 권장 |
| 256 lag 모두 | LLS에서는 lag마다 계산합니다(분석 도구가 클래스 평균으로 HW 근사도 시험합니다) |
| 확인 | 덤프가 나오면 `qRatio` ≈ 1, 열잡음에서 `rhoPk` ≪ 1 |

Π를 `z·conj(z)`로 잘못 계산하면 Π = Q가 되어 모든 탭에서 ρ = 1이 됩니다. 열잡음 덤프에서 `rhoPk`를 보면 바로 드러납니다.

### 4.3 하드웨어 관점 (참고)

- 입력 샘플마다 곱 3개(re², im², re·im). 위상 클래스(HPRF 8개, BPRF 16개)마다 누산기 3개.
- 판정: 클래스당 1회 π = Π/Q 계산, 신호 창 탭마다 곱 약 6개. 나눗셈 없는 비교식은 `|C|² − Re(π*·C²) ≥ (T/2)·Q·(1 − |π|²)`.
- 잡음 창 W_n, 빗 깊이 D, 두 단계 문턱은 필요 없어집니다.

### 5.3 `h0_pfa_analyze.m`

- 추가 옵션: `'PerClass'`(rif_cir_analyze로 전달), `'Margin'`, `'Moments'`(`'cir'`이면 2열 덤프에서도 Λ 표가 나옴).
- 캐시 키에 버전(2)과 PerClass를 추가해, 원본 캐시나 다른 설정의 캐시는 자동으로 다시 계산합니다.
- MD 표(`current thresholds`)에 κ 중앙값 열을 추가했습니다.
- 모든 조건이 5열이면 Λ 표를 추가로 출력합니다. 문턱은 `T = 2·ln(|W_s|/Target) + 2·ln(Margin)`으로 고정하고 탐색하지 않습니다.
  - 열: k, Pfa, 단측 Clopper-Pearson 상한, 판정, 탭 꼬리 비율 `P(Λ≥t)/e^(−t/2)` (t = 10, 14, 18), κ 중앙값
- 그림 `h0_lambda.png`: 조건별 탭 CCDF와 이론 e^(−t/2), 조건별 Pfa와 상한.
- MD 문턱 탐색(`'Suggest'`)은 원본과 같습니다.

### 5.4 `h1_pd_analyze.m`

- 폴더 규칙은 H0와 같습니다: `<root>/c<len>_m<power>_j<job>[/bin]`. 맞는 키로 만든 덤프여야 합니다(스크립트는 정답을 모르고 폴더로 구분합니다).
- 조건(길이, 세기)마다 MD 규칙(`valid`)과 Λ(`validL`) 각각에 대해 출력합니다.

| 지표 | 정의 |
|---|---|
| Pd | 검출된 프래그먼트 / 전체. 양측 Clopper-Pearson 신뢰구간 `[PdLo, PdHi]` (`'Conf'`, 기본 0.95) |
| PosAcc | 검출된 프래그먼트 중 피크 탭 `kpk`(W_s 안 \|C\|²의 argmax)가 `PeakTap ± Tol`(기본 127 ± 2)인 비율 |
| PdLoc | 위치까지 맞게 검출된 프래그먼트 / 전체 (= Pd × PosAcc) |
| L90, L99 / L90loc, L99loc | Pd / PdLoc가 0.9, 0.99에 닿는 세기 (1 dB 격자 선형 보간) |

- 추가 옵션: `'PeakTap'`(기본 127, 거리 0의 피크 탭), `'Tol'`(기본 2탭, 1탭 ≈ 1 ns ≈ 0.3 m), `'Conf'`(기본 0.95), `'Moments'`.
- 반환값: `table`(기존과 같은 [len, dBm, n, Pd(MD), Pd(Λ)]), `cond(c)`(조건별 k, kLoc, Pd, PdLo, PdHi, PdLoc, PosAcc와 검출된 프래그먼트의 위치 오차 `errMD`, `errL`), `L90`, `L99`, `L90loc`, `L99loc`(행 = 길이, 열 = [MD Λ]).
- 그림: 왼쪽은 Pd와 신뢰구간(점선 MD, 실선 Λ), 오른쪽은 위치 정확도.
- 위치는 검출 판정과 별개로 \|C\|²의 argmax로 정합니다(Λ는 고SNR에서 여러 탭이 포화하므로 위치용으로 쓰지 않습니다).
- 캐시가 없어 매번 덤프를 다시 읽습니다.

### 5.5 사용 시 주의

- **경로:** 같은 이름의 함수가 원본 폴더에도 있습니다. MATLAB은 현재 폴더를 path보다 먼저 찾으므로, 원본 스크립트가 있는 폴더가 아닌 곳에서 `addpath('<...>/lambda_patch', '-begin')`로 실행하고 `which rif_cir_analyze`로 확인합니다.
- **캐시 공유:** 원본과 패치를 같은 덤프 폴더에 번갈아 쓰면 캐시 키가 달라 매번 다시 계산합니다. 결과에는 영향이 없습니다.
- **폴더 이름:** `c<len>_m<power>_j<job>`, power는 정수 dBm의 절댓값입니다. 멀티패스나 CFO 조건은 root를 분리합니다.

## 8. 고정 칩 대안: CIR 추정 Λ̂ (`'Moments', 'cir'`)

### 8.1 목적

이미 만들어진 칩에는 Q·Π 누산기를 더할 수 없습니다. 펌웨어가 프래그먼트별 CIR(256탭, 복소)을 읽을 수 있다면, Q와 Π를 CIR에서 추정해 같은 판정을 할 수 있습니다. 하드웨어 변경 없이 펌웨어 연산만 늘어납니다.

### 8.2 근거와 알고리즘

H0에서 탭 k = 127 + 8m + e의 값은 위상 e의 펄스 모양 g(e)에 서로 독립인 랜덤 합 X_m을 곱한 것입니다(열잡음도 8탭 떨어진 탭끼리는 독립). 그래서 같은 위상의 탭은 위치와 상관없이 같은 분포를 따르고 서로 독립이므로, 신호 창 밖 같은 위상의 탭이 신호 창 안 탭의 Q·Π를 재는 표본이 됩니다.

```
Q̂_e = mean |C[k]|²,  Π̂_e = mean C[k]²        k ∉ W_s, k mod 8 = e   (신호 창 밖 199탭 → n_e = 24~25)
T²[k] = 2(Q̂|C|² − Re(Π̂*C²)) / (Q̂² − |Π̂|²)     (3.2절 식에 추정값)

H0:  P(T² ≥ t) = (1 + t/n)^(−(n−1)/2)          Hotelling T², p = 2 (n → ∞이면 e^(−t/2))
Λ_eq = (n−1)·ln(1 + T²/n)                     H0에서 정확히 χ²₂ → 같은 문턱 T = 22.71, 같은 탭 꼬리 검사
```

추정 잡음 때문에 문턱이 원시 샘플 Λ보다 높아집니다. 문턱 상승은 `10·log10(t_hot(n)/T)`이고, 위상당 표본 n = 25면 약 2.4 dB, n = 10(MD 잡음 창 81탭만)이면 약 7.0 dB입니다. 신호 창 밖 탭을 모두 써야 합니다.

### 8.4 사용과 확인

```matlab
R0c = h0_pfa_analyze('<H0 root>', 'Suggest', false, 'Moments', 'cir');   % 2열 덤프로도 가능
R1c = h1_pd_analyze('<H1 root>', 'Moments', 'cir');
```

- **전제 1:** 신호 창 밖 탭이 H0에서 신호 창 안과 같은 분포여야 합니다. CIR 양 끝의 누적 경계 효과, 16비트 포화가 있으면 깨집니다. H0 Λ 표의 탭 꼬리 비율(약 1)로 확인합니다.
- **전제 2:** H1에서 멀티패스 꼬리가 신호 창 밖까지 이어지면 Q̂가 커져 Pd가 떨어집니다(Pfa에는 영향 없음). 필요하면 `'CirNoise'`로 신호 창 바로 뒤를 빼고 추정합니다.
- **개선 여지:** CIR이 더 길거나, 같은 프레임의 여러 프래그먼트에서 Q̂를 모으면 n이 늘어 손해가 줄어듭니다. MMS 소프트 결합(3.5절)도 함께 쓸 수 있습니다.
- **펌웨어 연산:** 위상별 제곱합 2종(199탭), 위상별 2×2 역행렬 대신 3.2절의 나눗셈 없는 비교식, 문턱은 위상별 상수(n_e로 미리 계산).

## 9. 한계와 남은 일

- **모델 기반:** 모든 수치는 모델(이상 펄스, 부동소수점, 단일 안테나, HPRF) 값입니다. 실제 시뮬레이터 덤프로 다시 확인해야 합니다.
- **보장의 전제:** Λ의 H0 분포는 수신 신호가 내 키 시퀀스와 독립일 때 성립합니다. 키를 알거나 일부 아는 공격(재전송, 일부 비트 반전)은 대상이 아닙니다.
- **ToA:** 검출 위치 정확도는 \|C\|² argmax 기준입니다. 멀티패스에서는 argmax가 첫 경로가 아닌 경우가 많아(6.5절) ToA에는 첫 경로 탐색이 필요합니다.
- **보안 범위:** 표준이 RIF에 요구하는 ToA 무결성 검증(첫 경로 탐색, RSF ToA와의 일치)은 별도 과제입니다. 탭별 CFAR 성질은 첫 경로 탐색 문턱 설계의 근거로 쓸 수 있습니다.
- **HW 구현:** 고정소수점 비트폭, 데시메이션(일부 심볼만으로 Q·Π 누적), 클램프의 고정소수점 표현은 미정입니다. 데시메이션을 쓰면 Margin을 다시 확인해야 합니다.
- **BPRF:** 펄스 간격이 16탭이라 `'Period', 16`. 모델 검증은 HPRF만 했습니다.
- **창 배치:** 거리 ≠ 0에서는 W_s를 타이밍 불확실성만큼 넓힙니다. 2배로 넓혀도 문턱은 약 0.25 dB만 오릅니다.
- **MMS 결합:** 3.5절의 소프트 결합은 분석 도구에 아직 없습니다.
