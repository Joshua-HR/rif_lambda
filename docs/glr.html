판정기 수식 · 우도비 유도

Λ는 잡음 타원으로 잰 거리, Λ̂는 그 타원이 얼마나 부풀어야 하는지입니다

두 판정기는 모두 일반화 우도비(GLR)입니다. 탭 하나를 놓고 "잡음만 있다"와 "신호가 섞였다" 중 어느 쪽이 관측값을 더 잘 설명하는지 견줍니다. 잡음 통계 Q·Π를 알면 그 비는 잡음 타원의 눈금으로 잰 거리 Λ가 됩니다. 모르면, 바깥 탭으로 맞춘 잡음 타원이 관측값 하나 때문에 얼마나 부풀어야 하는지가 됩니다. 이 페이지는 그 유도를 그림 일곱 장으로 따라갑니다.

Λ = 2·ln GLR (잡음 통계를 앎) Λ̂ = (n−1)/(n+1) · 2·ln GLR (바깥 탭으로 추정) H0에서 둘 다 정확히 χ²₂ 문턱 22.71 (프래그먼트 1e-3)
1 · 문제 설정

탭 하나, 가설 둘

신호 창(119~175)의 탭마다 같은 질문을 합니다. 관측한 CIR 값 C가 잡음만으로 생긴 것인가(H0), 맞는 키 신호 a가 더해진 것인가(H1). 여기서 잡음은 열잡음과 틀린 키 신호의 자기잡음을 모두 뜻합니다(Λ̂ 판정기 원리 1장). a는 크기, 채널, 반송파 위상을 모두 모르는 복소수입니다.

2 · 잡음 타원

Q는 크기, Π는 납작함과 방향을 정합니다

C를 실수 두 개(Re C, Im C)로 보면 잡음은 2차원 가우시안이고, 확률 밀도가 같은 점들은 타원을 이룹니다. Q와 Π가 이 타원을 정확히 정합니다. 긴 축 방향의 분산은 λ₁ = (Q + |Π|)/2, 짧은 축은 λ₂ = (Q − |Π|)/2이고, 긴 축의 기울기는 arg Π의 절반입니다. 그래서 Q는 두 분산의 합(전체 세기), |Π|는 두 분산의 차(납작한 정도)이고, κ = |Π|/Q는 0(원)부터 1(선분)까지 납작함을 나타냅니다.

c̲ = [C, C*]와 R̲은 이 실수 2차원 표현을 복소수로 쓴 것입니다. C 하나와 Q만으로는 타원의 방향을 나타낼 수 없어서, C의 켤레와 Π를 함께 씁니다. 실수로 바꾸면 Var(Re C) = (Q + Re Π)/2, Var(Im C) = (Q − Re Π)/2, Cov(Re C, Im C) = Im Π/2입니다.

3 · 우도비에서 Λ로

모르는 a를 C로 맞추면 H0 쪽의 거리만 남습니다

우도비는 같은 관측값을 두 가설의 확률 밀도에 넣어 나눈 값입니다. 잡음이 비원형 가우시안이면 밀도는 다음과 같습니다.

p(C | H0)    = 1/(π√det R̲) · exp(−½ · c̲ᴴ R̲⁻¹ c̲)
p(C | H1, a) = 1/(π√det R̲) · exp(−½ · (c̲ − a̲)ᴴ R̲⁻¹ (c̲ − a̲)),   a̲ = [a, a*]

H1에는 모르는 a가 있으므로, 관측값을 가장 잘 설명하는 값(최우추정)으로 바꿔 넣습니다. 이것이 "일반화" 우도비입니다. 잡음 밀도는 중심에서 가장 높으므로 가장 잘 설명하는 값은 â = C이고, 그러면 H1의 지수항이 0이 됩니다.

GLR      = max_a p(C | H1, a) / p(C | H0)  =  exp(½ · c̲ᴴ R̲⁻¹ c̲)
2·ln GLR = c̲ᴴ R̲⁻¹ c̲
         = [C*, C] · [[Q, −Π], [−Π*, Q]] · [C; C*] / (Q² − |Π|²)
         = (2Q|C|² − Π C*² − Π* C²) / (Q² − |Π|²)
         = 2(Q|C|² − Re(Π*C²)) / (Q² − |Π|²)  =  Λ
4 · H0에서 χ²₂인 이유

타원을 원으로 펴면 Λ는 반지름의 제곱입니다

H0에서 C는 원점의 잡음 구름에서 나옵니다. 긴 축은 √λ₁로, 짧은 축은 √λ₂로 나눠 구름을 둥글게 펴면(백색화), 두 좌표 z₁, z₂는 서로 독립인 표준 정규가 되고 Λ = z₁² + z₂²가 됩니다. 표준 정규 두 개의 제곱합이 자유도 2인 카이제곱 χ²₂이고, 그 꼬리는 P(Λ ≥ t) = e^(−t/2)입니다. 실제 CIR은 수천 개 항의 랜덤 부호 합이라 가우시안에 가깝고, 꼬리가 가우시안보다 무겁지 않습니다(설계 문서 3.1절).

자유도 2는 H1에서 모르는 실수 파라미터의 개수, 곧 a의 실수부와 허수부입니다. 우도비 검정에서 일반적으로 성립하는 관계(Wilks 정리)인데, 잡음이 가우시안이면 근사 없이 정확합니다. a의 위상을 알고 크기만 모른다면 그 방향의 성분 하나만 남아 χ²₁이 됩니다.

5 · Λ̂: 잡음 통계까지 모를 때

C를 잡음으로 설명하려면 잡음 타원이 얼마나 부풀어야 하나

고정 칩에는 Q·Π 누산기가 없어 R̲도 모릅니다. 대신 같은 빗 위상의 바깥 탭 y₁ … yₙ(n = 24~25)이 H0 잡음의 표본입니다. 이제 두 가설은 각자 a와 잡음 타원을 가장 그럴듯하게 맞춥니다.

H1은 C를 신호로 설명하므로(â = C) C의 잔차가 0이 되고, 잡음 타원은 바깥 탭만으로 정해집니다. H0은 C까지 잡음으로 설명해야 하므로, 바깥 탭과 C를 함께 넣어 맞춘 타원이 C 쪽으로 부풉니다. 가우시안의 최대 우도는 맞춘 공분산의 행렬식(타원 넓이의 제곱)에만 달려 있어서, 우도비는 두 행렬식의 비가 됩니다.

S  = Σᵢ yᵢ yᵢᵀ   (바깥 탭의 산포 행렬, 실수 2×2),   x = [Re C, Im C]
H1:  Σ̂₁ = S / (n+1)          H0:  Σ̂₀ = (S + x xᵀ) / (n+1)
GLR = (det Σ̂₀ / det Σ̂₁)^((n+1)/2)
det(S + x xᵀ) / det S = 1 + xᵀ S⁻¹ x = 1 + T²/n     (행렬식 보조정리, T² = Λ 식에 Q̂·Π̂를 넣은 값)
2·ln GLR = (n+1) · ln(1 + T²/n)
6 · (n−1)/(n+1)의 뜻

곱한 상수는 판정을 바꾸지 않고 눈금만 χ²₂에 맞춥니다

T², 2·ln GLR, Λ̂는 서로의 증가 함수라 탭의 순서와 판정 결과가 같습니다. 다른 것은 잡음만 있을 때의 분포, 곧 눈금입니다. T²는 Hotelling 꼬리 P(T² ≥ t) = (1 + t/n)^(−(n−1)/2)를 따르고(설계 문서 8.2절), 이를 옮기면 2·ln GLR의 꼬리도 정확히 지수 함수입니다.

P(2·ln GLR ≥ g) = P(1 + T²/n ≥ e^(g/(n+1))) = e^(−g·(n−1) / (2(n+1)))
→ 2·ln GLR = (n+1)/(n−1) × χ²₂
→ Λ̂ = (n−1)/(n+1) · 2·ln GLR = (n−1)·ln(1 + T²/n)  ~  χ²₂  (정확)

우도비 검정의 일반 이론(Wilks)은 표본이 많을 때 2·ln GLR이 χ²₂에 가까워진다고만 말합니다. 여기서는 유한한 n에서의 차이가 정확히 상수배라, (n−1)/(n+1)을 곱하면 근사 없이 χ²₂가 됩니다. 평균을 χ²의 평균에 맞추는 보정(바틀렛 보정)과 같은 꼴인데, 이 경우에는 분포 전체가 정확히 맞습니다.
