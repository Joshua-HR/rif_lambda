5단계: FAIL은 비교 대상 세트의 경로 문제였습니다

5단계 스크립트 regress_length32는 길이 지원 전에 만든 세트(예전 세트)와 새 코드의 결과를 비교합니다. 두 번 돌린 결과 모두 새 코드로 만든 세트(C, D)는 PASS였고, 예전 세트 쪽(A, B)만 FAIL이었습니다.

64심볼 전체 세트: −40 dBm 조건의 Λ̂ 꼬리가 길이에 따라 바뀌었습니다

N64 FAIL N 64, 5 columns, full set 93 / 94 checks OK; CHECK cir h0: largest tail ratio t=10 = 1.307 (범위 0.7 .. 1.3) N64 FAIL N 64, 2 columns, full set 48 / 49 checks OK; CHECK 2col h0 cir: largest tail ratio t=10 = 1.307 (같은 CIR이라 같은 값)

이 판정은 Λ̂(CIR에서 Q·Π를 추정한 고정 칩 판정기)로 잡음만 있을 때, 탭마다 Λ̂ ≥ 10인 비율을 χ²₂의 기대값 e⁻⁵로 나눈 값입니다. H0 네 조건 중 가장 큰 값을 봅니다. 1에 가까워야 정상이고, 범위 0.7–1.3은 32심볼에서 쓰던 값입니다.

H0 꼬리·상관 판정 탐색기

새 규칙이 적용된 19개 판정을 하나씩 볼 수 있습니다. 점은 길이별 Python 값, 막대는 ±4σ(bootstrap)입니다. 연한 띠는 32심볼 범위, 진한 띠는 그 길이에서 쓰는 범위입니다. 64–256심볼에서 띠가 넓어진 만큼이 이번 수정입니다.
