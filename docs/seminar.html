1 · 문제 설정

점수 모듈을 못 쓰니 누적 CIR로 판정합니다

일반 모드에서는 SemiSync가 심볼 경계를 다시 잡은 뒤 점수 모듈과 CFO·SCO 추적이 돕니다. SemiSyncOnlyMode는 경계를 다시 잡지 않아 둘 다 꺼집니다(HW 정의). 남는 것은 프래그먼트(RIF 32~256심볼)마다 누적한 CIR 256탭이고, 잔여 CFO도 보상 없이 안고 갑니다.

측정 1회 프래그먼트 8개판정 재료 CIR 256탭잔여 CFO 보상 없음

1 · 문제 설정

탭마다 푸는 복합 가설 검정

판정 탭: 신호 창 W_s = 119~175, 57탭. 거리 0의 피크는 127탭입니다.

H0: C = w. 잡음은 열잡음과 틀린 키 신호의 자기잡음을 모두 뜻합니다.

H1: C = a + w. a는 크기·채널·반송파 위상을 모르는 복소수입니다.

요구사항: 측정 1회당 오수락 ≤ 10⁻⁶ (FiRa medium, 결정 1·2). 프래그먼트당 1e−3은 진단 기준입니다.

관측값은 탭마다 C 하나뿐이고 a를 모르므로, 일반화 우도비(GLRT)로 풉니다.

1 · 문제 설정

프래그먼트 하나의 CIR

세로축은 Z 판정기의 바닥(가장 높은 위상의 평균) 대비 dB라서, 피크 높이가 곧 Z 판정기의 판정값 Z입니다. 오른쪽에는 같은 프래그먼트의 판정값과 위상별 바닥이 나옵니다.

해 보세요. "맞는 키 · 강함"과 "틀린 키 · 강함"을 번갈아 누르세요. 둘 다 바닥이 8탭 주기로 출렁이지만(주기정상 잡음), 127탭에 우뚝 선 피크는 맞는 키에만 있습니다. "새 프래그먼트"로 다른 표본도 뽑아 보세요.

1 · 문제 설정

탭은 슬롯 안 같은 자리의 샘플만 씁니다

상관기 출력 C[k] = Σₙ bₙ·r[8n + k]는 수신 샘플을 8개씩 끊은 "펄스 슬롯"마다 같은 자리(k mod 8)의 샘플 하나씩에 내 키의 부호를 곱해 더합니다. 그 자리 e = k mod 8이 다상 성분(polyphase component)이고, 줄여서 위상 e라 부릅니다.

8탭 떨어진 탭(127과 135)은 같은 분포. 같은 숫자 묶음에 부호만 한 칸 밀려 붙습니다. 틀린 키에서는 부호가 무작위라, 같은 주사위를 두 번 던진 것과 같습니다.

1탭 떨어진 탭(126, 131)은 다른 분포. 펄스 중심에서 멀어질수록 숫자가 작아져, 위치가 다르면 주사위 자체가 다릅니다.

1 · 문제 설정

잡음 바닥은 8탭 주기로 변합니다: 주기정상(cyclostationary) 잡음

해 보세요. "신호 없음"에서는 여덟 위상이 모두 0 dB입니다. 세기를 올리면 펄스 중심인 위상 7과 이웃(6, 0)이 먼저 솟고, 펄스 사이인 위상 3은 늦게 따라옵니다. −40 dBm에서는 차이가 약 25 dB입니다.

주황 점선은 위상을 섞어 바깥 탭 199개를 평균한 값입니다. 이 값으로 위상 7을 재면 잡음을 작게 봐서 오검출이 크게 늘어납니다. 그래서 판정은 같은 위상끼리 비교해야 합니다. 틀린 키 잡음은 실수 ±1의 합이라 복소평면에서 한 방향으로 납작하기도 합니다(κ ≈ 0.99).

모델: lambda_patch/model (AWGN 펄스 모양, 위상별 기댓값 1 + A²·Σ|g|²). 탭당 오검출은 바깥 탭 24개 추정 기준(Hotelling)으로 계산

2 · 기존 Z 판정기 진단

기존 Z 판정기: 최대 바닥으로 나누고 문턱은 두 단계

① F[e]  = mean{ |C[k]|² : k ∈ W_n, k mod 8 = e }
② D     = max_e F[e] / min_e F[e]
③ Z     = max_{k∈W_s} |C[k]|² / max_e F[e]
④ valid = Z ≥ (D < 10 dB ? 9.6 dB : 14.4 dB)

RIF_CIR_Validity_Detector.md에 정의된 방식입니다. ① 피크 앞 잡음 창(16~96)에서 위상마다 탭 약 10개를 평균해 바닥을 잽니다. ② 가장 높은 바닥과 가장 낮은 바닥의 비(위상 간 바닥비 D)로 열잡음인지 강한 자기잡음인지 가늠합니다.

③ 신호 창에서 가장 큰 탭이 가장 높은 바닥보다 몇 배인지 봅니다. ④ D가 10 dB보다 작으면 9.6 dB, 크면 14.4 dB 문턱과 비교합니다. 두 문턱은 −120 dBm과 −40 dBm 두 끝점에 몬테카를로로 맞춘 값입니다.

해 보세요. 처음 화면 "틀린 키 −82 dBm"이 실제 오검출 사례입니다. 키가 맞지 않는데 위상 간 바닥비 D가 7.5 dB라 낮은 문턱(9.6 dB)이 적용되고, 신호 창의 143탭이 바닥보다 9.9 dB 튀어 문턱을 넘었습니다. "틀린 키 −40 dBm"은 D가 24.7 dB라 높은 문턱(14.4 dB)이 적용되어 거절됩니다. 바닥이 위상 10개 평균이라는 점(주황 점)도 함께 보세요.

2 · 기존 Z 판정기 진단

프래그먼트 수천 개를 결정 평면 (D, Z)에 찍으면

점 하나가 앞 장면의 프래그먼트 하나입니다. 가로축이 ② 위상 간 바닥비 D, 세로축이 ③ Z이고, 계단 모양 경계선이 ④ 2단 문턱입니다. 경계 위로 올라간 점이 오검출입니다.

해 보세요. 틀린 키 세기를 −90~−76 dBm으로 옮기세요. D가 아직 10 dB 아래(낮은 문턱)인데 Z만 위로 퍼져 경계를 넘는 점이 늘어납니다. 멀티패스로 바꾸면 위상 사이의 바닥 차이가 메워져 D가 낮아집니다.

2 · 기존 Z 판정기 진단

깨지는 원인 둘: 10표본 추정과 비원형 꼬리

① 바닥을 10표본으로 추정. 10개 평균은 ±1.4 dB 흔들리고, 바닥이 낮게 나온 프래그먼트에서 Z가 그만큼 부풉니다. 흔들림의 크기가 세기·채널마다 달라 문턱 하나로 덮을 수 없습니다.

② 틀린 키 자기잡음은 비원형. X = Σ bₙ·a₍ₙ₊ₘ₎은 실수라 같은 평균 전력이라도 전력이 한 축에 몰립니다. 꼬리가 자유도 1 카이제곱처럼 무거워, 9.6 dB 문턱에서 원형보다 23배 자주 넘습니다.

잔여 CFO 회전은 직선을 원 쪽으로 퍼뜨립니다(기존 문서의 측정에서 256심볼 오검출 0건). CFO를 보상하는 구성에서는 꼬리가 다시 무거워집니다.

2 · 기존 Z 판정기 진단

정규화는 크기를 맞추고, 백색화는 모양까지 폅니다

잡음을 문턱 하나로 판정하려면, 어떤 조건에서든 잡음이 같은 눈금 위에 있어야 합니다. 정규화는 잡음의 세기 Q로 나눠 크기만 맞추는 것이고, 백색화는 납작한 잡음의 긴 축과 짧은 축을 각자의 표준편차로 나눠 둥글게 펴는 것입니다. 둘을 다 한 것이 원시 샘플 Λ입니다.

① 원래 값

|C|²를 그대로 고정 문턱과 비교합니다. 잡음 세기가 바뀌면 같은 문턱이 전혀 다른 오검출을 줍니다. Z 판정기는 바닥 추정으로 나눠 이 단계를 벗어나려 하지만, 위상당 10표본이라 흔들립니다.

② 정규화: 2|C|²/Q

세기를 맞춰 열잡음에서는 정확합니다. 하지만 틀린 키처럼 납작한 잡음은 긴 축 방향으로 원 밖에 더 자주 나갑니다. 실제 문턱(탭당 1.2e−5)에서는 이 차이가 훨씬 커집니다(9.6 dB 문턱에서 23배).

③ 백색화: Λ

긴 축은 √((Q+|Π|)/2)로, 짧은 축은 √((Q−|Π|)/2)로 나누면 어떤 세기와 모양의 잡음도 같은 둥근 구름이 됩니다. Λ = 2(Q|C|² − Re(Π*C²))/(Q² − |Π|²) = z₁² + z₂²이고, 문턱 밖 비율이 정확히 목표값입니다.

해 보세요. "틀린 키 −40 dBm"에서 ① 원래 값을 보면 열잡음용 문턱(보라 원)이 점처럼 작아 거의 모든 점이 밖에 있습니다. ② 정규화로 크기를 맞추면 대부분 안으로 들어오지만, 긴 축 끝의 점들이 여전히 목표의 세 배쯤 나갑니다. ③ 백색화에서 비로소 1%가 됩니다. "열잡음"에서는 ②와 ③이 같습니다.

결과: 정규화와 백색화가 둘 다 필요합니다

3 · 원시 샘플 Λ

H0의 2차 모멘트는 추정하지 않고 계산합니다

① C[k]  = Σₙ bₙ · zₙ[k]
② Q_e   = Σₙ |zₙ[k]|²,  Π_e = Σₙ zₙ[k]²   (k mod 8 = e)
③ Λ[k]  = 2(Q|C[k]|² − Re(Π*C[k]²)) / (Q² − |Π|²)
④ valid = max_{k∈W_s} Λ[k] ≥ 22.71

① 탭 값은 내 키의 ±1(bₙ)과 수신 샘플(zₙ)의 곱의 합입니다. 맞는 키가 없으면 b와 z가 독립이라 C[k]는 랜덤 부호 합입니다.

② 그래서 잡음의 세기 Q와 모양 Π를 CIR 탭이 아니라 상관기에 들어간 원시 샘플로 정확히 계산합니다. 채널·CFO·세기와 무관하고, 32심볼이면 샘플 3,968개입니다(Z 판정기는 위상당 탭 10개로 추정). 같은 위상 클래스는 같은 샘플 집합이라 위상당 누산기 3개면 됩니다.

③ 신호 창의 탭마다 그 위상의 Q·Π로 잡음 타원 거리²를 잽니다(다음 장면). ④ 57탭 중 최댓값을 22.71과 비교합니다. 잡음 창 W_n은 필요 없습니다.

2차 모멘트의 뜻과 문턱 22.71의 유도펼치기접기

한 줄 요약. H0에서 탭 하나의 Λ가 t를 넘을 확률은 조건과 관계없이 정확히 e^(−t/2)입니다. 신호 창 57탭 중 하나라도 넘을 확률을 1e-3 ÷ 1.5 이하로 묶는 t가 22.71입니다.

  1. 12차 모멘트: Q와 Π는 무엇인가

    모멘트는 확률변수를 거듭제곱한 값의 평균입니다. 1차 모멘트는 평균 E[C]이고, 2차 모멘트는 C 두 개를 곱한 값의 평균입니다. 복소수 C에는 2차 모멘트가 두 가지 있습니다. C·C*의 평균이 세기(분산) Q이고, C·C의 평균이 의사분산 Π입니다.

    E[bₙ] = 0,   E[bₙbₘ] = 1 (n = m),  0 (n ≠ m)

E[C]  = Σₙ E[bₙ]·zₙ          = 0
E|C|² = Σₙ Σₘ E[bₙbₘ]·zₙzₘ*  = Σₙ |zₙ|²  = Q
E[C²] = Σₙ Σₘ E[bₙbₘ]·zₙzₘ   = Σₙ zₙ²    = Π

    H0에서 무작위인 것은 내 키의 부호 bₙ뿐이고, zₙ은 이미 받은 샘플입니다. 그래서 기댓값이 샘플의 합으로 정확히 떨어집니다. 이웃 탭으로 추정하지 않고 상관기 입력으로 계산할 수 있는 이유입니다.

    실수부 x와 허수부 y로 풀면, Q·Π 두 값이 (x, y)의 공분산 행렬을 모두 정합니다. 잡음 타원의 크기(Q), 납작함(κ = |Π|/Q), 긴 축 각도(θ = arg Π / 2)입니다. 열잡음처럼 위상이 고루 퍼지면 Π ≈ 0이라 원이고, 강한 틀린 키처럼 샘플이 한 방향으로 모이면 |Π| ≈ Q라 납작한 타원입니다.

    C = x + j·y
E[x²] = (Q + Re Π) / 2,   E[y²] = (Q − Re Π) / 2,   E[xy] = Im Π / 2

  2. 2H0 분포는 Q·Π로 완전히 정해집니다

    C는 원시 샘플 M개(32심볼이면 3,968개) 항의 합이라 중심극한정리로 평균 0인 2차원 가우시안에 가깝습니다. 가우시안은 1·2차 모멘트로 분포가 완전히 정해지므로, H0 분포 전체를 Q·Π로 압니다. 랜덤 부호 합은 sub-Gaussian이라 꼬리가 가우시안보다 무겁지 않습니다.

    v = [x, y]ᵀ ~ N(0, Σ)
Σ = ½ · [[Q + Re Π, Im Π], [Im Π, Q − Re Π]]
det Σ = (Q² − |Π|²) / 4

  3. 3백색화하면 식 ③이 나옵니다

    타원을 원으로 펴는(백색화) 거리² vᵀΣ⁻¹v를 C로 다시 쓰면 식 ③의 Λ입니다. 잡음 타원으로 잰 거리²(마할라노비스 거리²)입니다.

    vᵀΣ⁻¹v = 2·[ (Q − Re Π)·x² − 2·Im Π·xy + (Q + Re Π)·y² ] / (Q² − |Π|²)
       = 2·[ Q·(x² + y²) − Re Π·(x² − y²) − Im Π·2xy ] / (Q² − |Π|²)

|C|² = x² + y²,   Re(Π*·C²) = Re Π·(x² − y²) + Im Π·2xy

→  Λ = 2·(Q·|C|² − Re(Π*·C²)) / (Q² − |Π|²)                식 ③

  4. 4탭 하나의 꼬리: 정확히 e^(−t/2)

    w = Σ^(−½)·v는 서로 독립인 표준 가우시안 두 개라, Λ = w₁² + w₂²는 자유도 2인 카이제곱 χ²₂입니다. 2차원 표준 가우시안을 극좌표로 적분하면 꼬리가 바로 나옵니다.

    P(Λ ≥ t) = ∫_√t^∞ r·e^(−r²/2) dr = e^(−t/2)

    세기·채널·CFO·납작함은 모두 Q·Π에 들어가 있어서, 어떤 조건에서도 꼬리가 같습니다. 문턱 하나로 모든 조건을 덮을 수 있는 이유입니다.

  5. 5신호 창 57탭으로 묶기: 합집합 한계

    판정은 신호 창 W_s(119~175, 57탭)의 최댓값이 문턱을 넘는가입니다. 한 탭이라도 넘을 확률은 각 탭이 넘을 확률의 합보다 클 수 없습니다. 탭끼리 상관이 있으면 실제 값은 이보다 작으므로 보수적인 한계입니다.

    P( max_{k∈W_s} Λ[k] ≥ T )  ≤  Σ_{k∈W_s} P(Λ[k] ≥ T)  =  57 · e^(−T/2)

  6. 6목표 1e-3과 여유 1.5를 넣으면 22.71

    이 한계를 프래그먼트 목표 Pfa = 1e-3을 여유 1.5로 나눈 값에 맞춥니다. 여유 1.5는 Q·Π를 유한 표본으로 계산하는 오차를 덮습니다(설계 문서 3.3절).

    57 · e^(−T/2) = Pfa / Margin = 1e-3 / 1.5 = 6.7e-4

T = 2·ln(57 / 1e-3) + 2·ln 1.5
  = 2 × 10.951      + 2 × 0.405
  = 21.90           + 0.81
  = 22.71

  7. 7감 잡기

    Π = 0(열잡음)이면 Λ = 2|C|²/Q라, 22.71은 |C|²/Q ≥ 11.36, 곧 피크가 그 위상의 잡음 세기보다 10.55 dB 높아야 한다는 뜻입니다. 같은 식에 Pfa = 10⁻⁶을 넣으면 36.53(12.62 dB)이고, RIF가 1개인 패킷의 문턱입니다. 식에는 신호 창 탭 수와 목표 Pfa만 들어가고, RIF 길이·PRF·세기·채널·CFO는 들어가지 않습니다.

    확인(κ = 0.98로 납작한 샘플 400개를 고정하고 부호 bₙ을 20만 번 뽑음): Λ ≥ 14인 비율 8.2e-4, 이론 e^(−7) = 9.1e-4. Π를 무시한 2|C|²/Q ≥ 14는 7.7e-3으로 8배 많습니다.

해 보세요. 처음 화면은 2부에서 기존 Z 판정기가 오검출한 바로 그 프래그먼트입니다. Z 판정기는 위상 7의 바닥을 잡음 창 탭 10개로 2.8 dB라고 추정했지만, 원시 샘플로 계산한 Q는 7.0 dB입니다. 그래서 143탭의 Λ는 문턱보다 한참 아래이고, 원시 샘플 Λ는 이 프래그먼트를 거절합니다. "맞는 키 −110 dBm"에서는 127탭 하나만 문턱 위로 솟습니다.

3 · 원시 샘플 Λ

Q와 Π가 잡음 타원을 정하고, Λ는 그 타원으로 잰 거리입니다

해 보세요. 처음 화면이 강한 틀린 키의 함정입니다. C가 긴 축 위에 있으면 Π를 무시한 원 밖(오검출)이지만, Λ로는 타원 안이라 검출되지 않습니다. "짧은 축 위"를 누르면 반대로 |C|가 작아도 Λ가 큽니다. κ를 0으로 내리면 타원이 원이 되어 두 판정이 같아집니다.

Λ = (2|C|²/Q)·(1 − κ·cos 2(φ − θ)) / (1 − κ²). 같은 |C|라도 방향에 따라 (1 + κ)/(1 − κ)배까지 다릅니다(κ 0.98이면 99배).

3 · 원시 샘플 Λ

Λ는 미지 진폭에 대한 GLRT입니다

GLRT(Generalized Likelihood Ratio Test, 일반화 우도비 검정)는 판정에 필요한 값 중 모르는 것이 있을 때 쓰는 표준 가설 검정입니다.

1 · 우도비 검정

두 가설의 확률 밀도를 모두 알면 p(C | H1) / p(C | H0)를 문턱과 비교합니다. "이 관측값이 신호가 있을 때 나올 법한 정도가 잡음만일 때의 몇 배인가"를 재는 것이고, 정해진 오검출에서 검출 확률이 가장 높은 판정입니다(Neyman–Pearson).

2 · 모르는 값이 있으면

H1의 신호 a는 크기·채널·반송파 위상을 모릅니다. a를 모르면 p(C | H1)이 하나로 정해지지 않아 1을 그대로 쓸 수 없습니다.

3 · 일반화: 최우추정으로 채우기

모르는 값을 관측값을 가장 잘 설명하는 값으로 채운 뒤 비교합니다: GLR = max_a p(C | H1, a) / p(C | H0). "신호 가설을 최대한 유리하게 맞춰 준 뒤에도 잡음 가설보다 얼마나 더 잘 설명하나"입니다. CIR 추정 Λ̂처럼 잡음 통계도 모르면 분모도 같은 방식으로 맞춥니다.

p(C | H0) ∝ exp(−½ · cᴴ R⁻¹ c)
c = [C, C*],   R = [[Q, Π], [Π*, Q]]

GLR = max_a p(C | H1, a) / p(C | H0)
â = C  →  2·ln GLR = cᴴ R⁻¹ c

Λ = 2(Q|C|² − Re(Π*C²)) / (Q² − |Π|²)

H1에서 a를 C로 맞추면 지수항이 0이 됩니다. 두 가설의 정규화 상수가 같으니, 남는 것은 H0 쪽의 거리(마할라노비스 거리²)뿐입니다. 오른쪽 단면에서 두 로그 밀도의 꼭짓점 높이는 같고, C에서의 높이 차이 Λ/2가 곧 ln GLR입니다. Π = 0이면 Λ = 2|C|²/Q로 기존 Z 판정기의 Z와 같은 꼴이 됩니다.

2·ln GLR은 H0에서 χ²를 따르고, 자유도는 모르는 파라미터 수입니다(Wilks 정리). 여기서는 가우시안이라 근사 없이 정확히 χ²₂(a의 실수부와 허수부)이고, 그래서 다음 장면처럼 문턱을 공식으로 정합니다. 위상을 모르는 이런 문제에는 모든 경우에 가장 강한 검정이 따로 없어서 GLRT가 실용적인 표준입니다. 백색·원형 잡음에서는 GLRT가 곧 에너지 검출 |C|²/σ²이고, 기존 Z 판정기의 Z가 이 꼴입니다.

3 · 원시 샘플 Λ

타원을 원으로 펴면 H0에서 정확히 χ²₂, 문턱은 공식입니다

백색화하면 Λ = z₁² + z₂²이고, 자유도 2는 a의 실수부와 허수부입니다. 문턱은 탭당 꼬리 e^(−T/2)에 합집합 한계와 유한 샘플 오차를 덮는 1.5배 여유를 둡니다.

CIR 추정 Λ̂의 우도비 유도

S = Σᵢ yᵢyᵢᵀ,   x = [Re C, Im C]
H1: Σ̂₁ = S/(n+1)
H0: Σ̂₀ = (S + xxᵀ)/(n+1)
GLR = (det Σ̂₀ / det Σ̂₁)^((n+1)/2)
det(S + xxᵀ)/det S = 1 + xᵀS⁻¹x = 1 + T²/n
2·ln GLR = (n+1)·ln(1 + T²/n)
P(2·ln GLR ≥ g) = e^(−g(n−1)/(2(n+1)))
Λ̂ = (n−1)/(n+1)·2·ln GLR ~ χ²₂

yᵢ: 같은 위상 바깥 탭 n개(실수 2차원). H1은 C의 잔차가 0이라 바깥 탭만으로, H0은 C까지 넣어 공분산을 맞춥니다. 출처: docs/glr.html 5·6장, 설계 문서 8.2절
